# Website Biography - Trần Trung Kiên

## Tối ưu siêu mượt 120Hz:
1. **Phần cứng GPU Acceleration**: Sử dụng `transform3d` và `will-change` cho toàn bộ các hiệu ứng chuyển động, hover và ánh sáng chuột giúp tận dụng tối đa tần số quét cao (120Hz/144Hz) trên các dòng máy màn hình cao cấp.
2. **Lerp thông minh**: Tốc độ chuyển động của ánh sáng theo chuột được tinh chỉnh độ trễ cực thấp (`0.22`), triệt tiêu giật lag, mang lại cảm giác siêu mượt và phản hồi tức thì.
3. **Hiệu ứng mượt mà**: Các đường cong chuyển động cubic-bezier được tối ưu riêng biệt cho cảm giác lướt web cao cấp, mượt mà.
